# Vey Server (`veysrs`) v0.4.0 Technical & Hardening Specification

`veysrs` v0.4.0 expands the pure Rust HTTP/1.1 static server foundation with **ETags**, **Conditional Requests (`304 Not Modified`)**, **HTTP Range Requests (`206 Partial Content` & `416 Range Not Satisfiable`)**, and **Clippy Cleanliness** (`-D warnings`).

---

## 1. New HTTP/1.1 Protocol Features

### A. ETag Generation & Validation
- **Format**: `"\"<mtime_hex>-<size_hex>\""` (e.g. `"\"6a7c0f71-42a\""`).
- **Header**: Included on all static file `200 OK` and `206 Partial Content` responses.
- **Conditional Evaluation**:
  - `If-None-Match`: Client provides expected ETag string. If matched, `veysrs` returns `HTTP/1.1 304 Not Modified` with zero body.

### B. Last-Modified & Conditional If-Modified-Since
- **Format**: IMF-fixdate / RFC 7231 (`Wdy, DD Mon YYYY HH:MM:SS GMT`).
- **Header**: Included on all static file responses.
- **Conditional Evaluation**:
  - `If-Modified-Since`: Client provides timestamp. If file `mtime <= parsed_time`, `veysrs` returns `HTTP/1.1 304 Not Modified` with zero body.

### C. HTTP Range Requests (`206 Partial Content` & `416 Range Not Satisfiable`)
- **Header Handled**: `Range: bytes=start-end`, `bytes=start-`, `bytes=-suffix`.
- **206 Partial Content Response**:
  - Headers: `Content-Range: bytes start-end/file_size`, `Content-Length`, `ETag`, `Last-Modified`, `Accept-Ranges: bytes`.
  - Streaming: Uses `BodySource::FileRange` to stream the exact requested byte offset and length using bounded 64KB stack memory buffers.
- **416 Range Not Satisfiable Response**:
  - Returned when requested start byte exceeds `file_size` or start > end.
  - Header: `Content-Range: bytes */file_size`.

## 2. Resource Limits & Hardening Summary

| Feature | Boundary Limit | HTTP Response Code |
| :--- | :--- | :--- |
| **URI Length** | 8,192 bytes | `414 URI Too Long` |
| **Header Line Length** | 8,192 bytes | `431 Request Header Fields Too Large` |
| **Max Headers** | 64 headers | `431 Request Header Fields Too Large` |
| **Header Block Size** | 16,384 bytes | `431 Request Header Fields Too Large` |
| **Request Body Size** | 65,536 bytes | `413 Payload Too Large` |
| **Concurrent Connections** | 1,024 connections | `503 Service Unavailable` |
| **Socket Timeouts** | 10 seconds | `408 Request Timeout` / Socket Close |
| **Invalid Byte Range** | Out of bounds | `416 Range Not Satisfiable` |
