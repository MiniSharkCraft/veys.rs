# `veysrs` v0.3.0 Technical Hardening Specification

## 1. Resource Limits & Defaults

| Limit Name | Default Value | Description | HTTP Error Status |
| :--- | :--- | :--- | :--- |
| `MAX_REQUEST_SIZE` | 65,536 bytes (64 KB) | Maximum total HTTP request size (headers + body) | `413 Payload Too Large` |
| `MAX_HEADER_SIZE` | 16,384 bytes (16 KB) | Maximum size for HTTP headers block | `431 Request Header Fields Too Large` |
| `MAX_HEADERS` | 64 headers | Maximum number of header fields per request | `431 Request Header Fields Too Large` |
| `MAX_HEADER_LINE` | 8,192 bytes (8 KB) | Maximum line length for a single header or request line | `431 Request Header Fields Too Large` / `414` |
| `MAX_URI_LENGTH` | 8,192 bytes (8 KB) | Maximum URI string length | `414 URI Too Long` |

## 2. Timeouts & Connection Management

| Setting Name | Default Value | Mechanism |
| :--- | :--- | :--- |
| `READ_TIMEOUT` | 10 seconds | `TcpStream::set_read_timeout` |
| `WRITE_TIMEOUT` | 10 seconds | `TcpStream::set_write_timeout` |
| `KEEP_ALIVE_TIMEOUT` | 10 seconds | Stream idle wait timeout before connection drop |
| `MAX_CONNECTIONS` | 1024 connections | `AtomicUsize` active connection guard; returns `503 Service Unavailable` when exceeded |
| `MAX_REQUESTS_PER_CONNECTION` | 100 requests | Maximum pipelined requests before emitting `Connection: close` |

## 3. Security Protections & Behaviors

- **Double Encoding Prevention**: Recursive percent decoding up to 2 passes to neutralize double-encoded traversal (`%252e%252e` -> `%2e%2e` -> `..`).
- **Dotfile Policy (`DENY_HIDDEN_FILES = true`)**: Denies access to files/directories starting with `.` (e.g. `/.veysrule`, `/.git/config`, `/.env`) with `403 Forbidden`.
- **Worker Panic Isolation**: Worker threads handle closures within `std::panic::catch_unwind`, isolating individual request panics from crashing worker threads or the server process.
- **Graceful Shutdown**: On SIGINT (Ctrl+C), listener stops accepting new sockets, signals worker channels to close, and joins all worker threads before process exit.
